## 설치
1. 늘 켜 두는 PC 에서 설치 파일 실행 — Windows 'PC 보호' 창이 뜨면 **추가 정보 → 실행**.
2. 브라우저의 **처음 설정**(회사·관리자) → 로그인 → 관리자 2단계 인증 → **시작하기** 점검표.
3. 라이선스가 없으면 30일 시험 사용입니다. 받은 라이선스 파일은 관리 > 시스템 관리 > 접속·라이선스에 넣습니다.

## 1.0 에 든 것
- 전자결재(합의·전결·대결·자동 결재선·일괄 승인), 근태(출퇴근 정정·근무 계획 신청, 공휴일 달력), 임금명세서·전자 근로계약·연차 촉진
- 인사 통계·노무 위험, 인사 기록(근로자 명부·임금대장 엑셀, 건강검진·출산/육아·자격증 알림, 경조사), **인사평가**(목표·역량·1차/2차·동료·등급 조정·이의 신청)
- 메신저(근무 상태)와 **PC 메신저**(트레이·Windows 알림 — 결재·인사평가 알림까지, 알림 잠시 끄기, Ctrl+Alt+N), 게시판(공지 자동 번역·임시 저장·예약·익명), 메일(예약 발송·수신 확인·발송 취소), 문서함(휴지통·바깥 공유 링크), 프로젝트(보드·표·달력)
- 사내 AI(회사 서버) 또는 **외부 AI 연결 — Claude·Gemini·GPT**(부가 기능, 회사의 API 키)
- 6개 언어(한국어·영어·베트남어·인도네시아어·중국어·일본어), 2단계 인증·패스키, 매일 암호화 백업, 시작하기 점검표

이미 설치한 회사는 새 설치 파일을 실행하면 데이터·설정은 그대로 새 버전으로 바뀝니다.
